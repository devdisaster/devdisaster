# Collabute X TheBlock. Hackathon: Agent Brief

You are helping a team build a project at a one-day AI hackathon at TheBlock, Dubai (30 August, 10:30 AM to 5:00 PM GST). Read this whole brief before writing any code.

## The goal
Build an original AI-powered product that solves a real problem. Any domain is fine: dev tools, AI agents, productivity, enterprise, fintech, education, collaboration, knowledge management, consumer apps, creative tools, or social impact. This is not a pitch-deck competition. The output is a working, demonstrable prototype.

## Required stack (all three, meaningful use)
Every eligible submission must genuinely use ALL THREE partner technologies. Each must contribute directly to the product's development, infrastructure, functionality, context system, or UX. Installing an SDK without using it, or mentioning a tool in the presentation, does not count and can disqualify the team from prizes.

1. **Devin by Cognition** (https://devin.ai): AI software engineer. Use it to build substantial parts of the product, and be ready to explain what it built. Docs: https://docs.devin.ai. Claim credits at https://www.devinvendingmachine.com/
2. **Convex** (https://convex.dev): the realtime backend. Database, queries, mutations, and live-updating UI. No credit code. Hackathon guide: https://convex-dev.notion.site/Convex-Sponsored-Hackathons-Guide-286b57ff32ab80daaa12dc4f8853f621 Docs: https://docs.convex.dev
3. **Context.dev** (https://context.dev): the web context API for AI agents. Scraping, crawling, structured extraction, brand/company intelligence, or change monitoring, whatever the product needs. Docs: https://docs.context.dev. Credits: sign up and complete onboarding, then redeem at https://www.context.dev/dashboard/redeem-credits with code COLLABUTE-CONTEXT-DEV.

Other APIs, models, libraries, and tools are welcome, but they supplement the three partners, never replace them.

## Hard rules
- All meaningful development happens during the event. Prepared scaffolding, design systems, and general libraries are fine; pre-built products are not eligible.
- Original work by the team. Open source and AI coding tools are allowed; disclose major pre-existing components in the submission.
- Use test or synthetic data only. Nothing that facilitates fraud or harm.
- The 5:00 PM GST submission deadline is strict. No extensions.

## Submission (due 5:00 PM sharp, via https://collabute-hackathon.vercel.app)
Required fields: project name, one-line description, problem being solved, target users, a paragraph each on how Devin, Convex, and Context.dev were used, a repository link, and optional demo and video links. Disclosure of pre-existing assets if any.

## Judging criteria (weighted)
- Product Value: 25%
- Technical Execution: 25%
- Partner Technology Integration: 25%
- Innovation: 15%
- Demonstration and Clarity: 10%

## How to work with me
- Optimize for a working core user journey over breadth. A small product that demos flawlessly beats a big one that crashes.
- Keep the demo path stable and rehearsed. The team presents roughly 3 minutes: the problem, the product, working functionality, how the three partner tools were used, and the potential impact.
- A deployed app is not required; a local prototype that clearly works is accepted.
- Flag integration risks early so there is time to fix them before 5:00 PM.
